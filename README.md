# Bloxd Painter

[Bloxd](https://bloxd.io/) 向けのマップ・地形を作成するための、ブラウザ上で動作する地形エディタです。

🔗 **Live Demo:** https://kentaki65.github.io/Bloxd-Painter/

## 概要

上から見た2Dビューで地形の高さ・ブロック・レイヤーをブラシで直感的に編集できるツールです。
描画パイプラインはWebGL2ベースで、ハイトマップ・ブロックID・レイヤー情報をGPUテクスチャとして保持し、陰影・等高線・chunkグリッド線までフラグメントシェーダー側で計算することで、広いマップでも滑らかな操作感を実現しています。

## 主な機能

### 地形編集
- **高さブラシ**：盛り上げ / 削る / 平坦化 / スムージングなど、複数のブラシモードで地形の高さを編集
- **ブロックペイント（スプレー）**：地表のブロック種類を、強度・密度を調整しながらペイント
- **レイヤーペイント**：見た目上の色分け用レイヤーを地形上に自由に描画・消去。カスタムレイヤーの追加・削除にも対応し、色と名前はブラウザ内（IndexedDB）に保存されます
- **範囲フィルタ**：高さや傾斜角の上限・下限を指定し、条件に合うセルだけにブラシを適用可能

### 表示・操作
- パン・ズーム対応のマップビュー
- 高低差に応じた陰影表現
- 等高線表示
- chunk境界のグリッド表示
- undo / redo による編集履歴管理

### スキーマティック・スタンプ
- `.bloxdschem` ファイルを読み込み、指定したレイヤー上にポアソンディスクサンプリングで自然な間隔で自動配置（密度・最小間隔を調整可能）
- 配置はエクスポート時にのみ適用され、編集中のワールドデータ自体は変更されません

### データの入出力
- マップ状態のJSON保存・読み込み
- `.bloxdschem` 形式でのエクスポート
- 作業内容はブラウザのIndexedDBに自動保存され、リロード後も復元可能

### パフォーマンス
- 地形の高さ計算は専用のWorkerスレッドで実行し、SharedArrayBufferで描画側と共有することでUIの応答性を確保
- 地形描画はWebGL2による一括レンダリングで、色計算・陰影・等高線・グリッド線をすべてGPU側で処理
- 編集された範囲のみを差分更新することで、広いマップでも快適な描画性能を維持

## 使用技術

- TypeScript
- WebGL2（GLSL ES 3.00 シェーダー）
- Web Workers / SharedArrayBuffer
- IndexedDB
